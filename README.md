# Tabletop Events Calendar — Carpool

A "need a lift / have spare seats" board for [Tabletop Events Calendar](https://github.com/TABARC-Code/tabletop-gaming-events-calendar) events.

**Not built yet.** This repo is reserved ahead of time, same as the rest of this family of plugins.

The idea: anchored on a specific event ID (same pattern as `[tabletop_organiser_events]`), someone offers or asks for a lift to that event without an admin having to broker it by hand — genuinely useful for the rural/grassroots gaming scenes this calendar already serves, where "I'd come if I could get there" is a real barrier.

Requires [Tabletop Events Calendar](https://github.com/TABARC-Code/tabletop-gaming-events-calendar) once it exists.
